# Privacy Policy for HA Sleep Sync

Last updated: October 24, 2026

## Overview
HA Sleep Sync is a personal tool that writes sleep timing data from the developer's own Home Assistant instance to the developer's own Google Health account. It is used only by its developer.

## Data accessed
The app requests access to Google Health sleep data through the Google Health API, solely to create sleep entries (start and stop times) in the account of the person who authorized it.

## How data is used
Data is used only to write sleep entries to that Google Health account. It is not used for advertising, analytics, profiling, or any other purpose.

## Data sharing
No data is sold, shared, or transferred to any third party.

## Data storage
The app stores no user data on any server. OAuth credentials (client ID, client secret, and refresh token) are stored only on the developer's private Home Assistant instance.

## Google API Services User Data Policy
The use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Data deletion and access revocation
Access can be revoked at any time at https://myaccount.google.com/permissions. Sleep data can be deleted from within the Google Health app.
